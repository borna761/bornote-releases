# borNote support

Need help with borNote, found a bug, or have an idea?

- **Report a problem or request a feature:** [open an issue](https://github.com/borna761/bornote-releases/issues/new). Please say which macOS version you use and what you expected to happen.
- **Browse known issues:** [github.com/borna761/bornote-releases/issues](https://github.com/borna761/bornote-releases/issues)
- **Email:** borna.safai@gmail.com

Your notes are plain Markdown files in the folder you picked, so they stay readable and safe even if something goes wrong in the app. Please don't attach private notes to a public issue.

See also the [privacy policy](privacy) and the [downloads](https://github.com/borna761/bornote-releases/releases/latest).
